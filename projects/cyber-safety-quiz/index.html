Cyber Safety Quiz

A proposed set of short bilingual quizzes, one for each awareness guide, so learners can test what they understood and see the correct safety action.

ConceptSecurity AwarenessWeb Development

This entry is currently marked Concept. Scope, status and results are still being confirmed, so no working features, performance figures or deployments are claimed.

Problem statement

Reading a guide does not always change behaviour. Short questions with instant feedback help people remember what to do in a real situation.

Technologies used

Technology stack to be confirmed.

Features

  • Planned: 5 questions per guide in English and Hindi
  • Planned: instant feedback explaining the safe action
  • Planned: no sign-up and no personal data collected

Screenshots and demonstration

Screenshots and a demonstration will be added when available.

Limitations

Concept stage only. Nothing has been built yet and no learning results are claimed.

Future improvements

  • Write the questions from the existing guides
  • Pilot the quiz with a small group of volunteers
